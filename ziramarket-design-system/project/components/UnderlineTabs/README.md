# UnderlineTabs

تب‌های صفحه‌ی جزئیات با خط زیر گرادیان ۳px.

صفحه‌ی جزئیات، ویرایش و پروفایل **همان ۶ تب فرم افزودن** را دارند با همان نام و ترتیب: اطلاعات هویتی، آدرس و تماس، اطلاعات بانکی، اطلاعات شغلی، مدارک، امنیت و نقش (افشین 2026-10-20). بخش‌های اضافه در تب مرتبط می‌آیند (دپارتمان در شغلی؛ نقش، وضعیت، رمز و نشست‌ها در امنیت و نقش).
