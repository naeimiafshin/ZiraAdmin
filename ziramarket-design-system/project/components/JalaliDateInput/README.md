# JalaliDateInput

فیلد تاریخ شمسی با تقویم در portal؛ مقدار «۱۴۰۵/۰۸/۰۸» و تایپ دستی ممکن.

همه‌ی فیلدهای تاریخ شمسی‌اند (قانون 2026-10-19). تقویم هم‌تراز لبه‌ی راست فیلد، Esc/Tab می‌بندد، اگر پایین جا نباشد بالا. تبدیل: `jalaliTextToGregorian(text)` (نامعتبر ⇐ null) و `gregorianToJalaliText`. انقضای نقش و بازه‌ی تاریخ فیلترها به‌صورت پایان/آغاز روز تهران (`+03:30`) فرستاده می‌شود.
