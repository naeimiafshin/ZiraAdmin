# Button

دکمه‌ی پنل در چهار نوع (primary، secondary، ghost، danger) و سه اندازه (sm، md، lg) با حالت بارگذاری.

## کی استفاده شود
- **primary**: عمل اصلی هر صفحه یا مودال، فقط یکی در هر ناحیه («افزودن کاربر جدید»، «ثبت کاربر»، «ذخیره‌ی تغییرات»). گرادیان `brand-gradient` با سایه‌ی `shadow-brand`.
- **secondary**: عمل‌های کنار عمل اصلی و دکمه‌های داخل کارت («ویرایش»، «تنظیمات اعلان‌ها»، «افزودن گروهی کاربران»).
- **ghost**: «انصراف»، «بازگشت به ورود»، «ارسال دوباره‌ی کد».
- **danger**: هر عمل خطرناک یا برگشت‌ناپذیر («حذف»، «اتمام نشست»، «خروج از همه‌ی دستگاه‌ها»). **کادر و متن قرمز روی سفید**، نه دکمه‌ی پر قرمز (قانون افشین).

## اندازه‌ها
| size | ارتفاع | کاربرد |
|---|---|---|
| `md` (پیش‌فرض) | `control-height` 42px، گردی 13px | همه‌جا؛ داخل سلول جدول خودکار 30px |
| `sm` | `badge-height` 26px، قرص | داخل جدول کنار Badge، ابزارهای سربرگ کارت |
| `lg` | 50px | فقط صفحه‌ی ورود (با `block`) |

## props
`variant`، `size`، `icon` (آیکون Tabler اندازه‌ی 17؛ در sm اندازه‌ی 15)، `loading` + `loadingText` (Spinner جای آیکون، `aria-busy`)، `block`، و همه‌ی propهای `<button>` (از جمله `data-tip` برای راهنمای شناور).

## باید و نباید
- دکمه‌ی فقط‌آیکونی حتماً `aria-label` دارد (راهنمای شناور از همان خوانده می‌شود).
- دکمه‌ای که شرطش برقرار نیست **غیرفعال** است و `data-tip` دلیلش را می‌گوید؛ کلیک بی‌صدا ممنوع.
- قابلیت بدون بک‌اند: دکمه‌ی غیرفعال + `SoonTag`.
- متن دکمه فعل دقیق است: «ثبت نقش»، «تخصیص نقش به ۳ کاربر»؛ هنگام کار «در حال ذخیره…».
