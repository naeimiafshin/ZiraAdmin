# Alert

کادر پیام خطا یا اطلاع بالای فرم (ورود، ویزارد، مودال)؛ متن خطای بک‌اند همان‌طور.

`tone="danger"` (پیش‌فرض، `role=alert`) یا `info` (`role=status`). برای نمایش **متن** خطا (پیام فارسی بک‌اند یا پیام ساخته‌شده) همیشه `Alert`؛ `ErrorBox(new Error(متن))` متن را عمومی می‌کند. `footer` برای کد پیگیری (Request ID) در خطای ۵xx. چند قاعده‌ی رمز در چند سطر: متن با `\n` و `white-space: pre-line`.
