# Select

فهرست کشویی فرم با API همان select بومی (با Dropdown رندر می‌شود).

`options[{value,label}]` و `placeholder` («انتخاب نقش»؛ هنگام بارگذاری «در حال دریافت…»). `<select>` و `datalist` خام در پنل ممنوع‌اند (قانون 2026-10-23). مقدار در `<select>` بومی پنهان نگه داشته می‌شود؛ react-hook-form و `select()` تست‌ها کار می‌کنند. استان، شهرستان و شهر همیشه کشویی از فهرست رسمی تقسیمات کشوری.
