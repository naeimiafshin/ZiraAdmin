# ListPage

الگوی صفحه‌ی فهرست (کاربران): PageHead با عمل اصلی، کارت با TableFilters، DataTable و Pagination.

الگوی `UsersListPage`:
1. `PageHead actions` = دکمه‌ی «افزودن <موجودیت> جدید» با `IconPlus`، فقط با مجوز ساخت (بی‌مجوز پنهان).
2. یک `Card`: `TableFilters` (فیلترهای تأییدشده‌ی افشین) ⇐ `DataTable` (ستون «ردیف»، کد، نام…، وضعیت با Badge) ⇐ `Pagination` (فقط `total>0`).
3. حالت لیست (صفحه، اندازه، `query`، فیلترها، تب) در URL با `replace` (`useListParams`)؛ «بازگشت» همان حالت را برمی‌گرداند.
4. اگر بک‌اند فیلتر یا جست‌وجو ندارد و فهرست کوچک است، کل فهرست یک بار (`fetchAll`، `page_size=100`) گرفته و در فرانت با `searchKey` فیلتر و صفحه‌بندی می‌شود؛ کمبود بک‌اند ثبت می‌شود.
5. کلیک ردیف ⇐ جزئیات (فقط با مجوز خواندن). دو متن خالی: با فیلتر / بی‌داده.

نمونه‌ی واقعی: `assets/Screens/02-users-list.webp`. داده‌ی پیش‌نمایش نمونه است.
