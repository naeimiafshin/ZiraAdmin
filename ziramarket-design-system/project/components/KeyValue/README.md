# KeyValue

جفت برچسب و مقدار برای صفحه‌های جزئیات؛ مقدار خالی «—».

برچسب `hint` (11.5px، `ink-400`) بالای مقدار `kv-value` (14px/700، `ink-900`). در شبکه‌ی دوستونه با فاصله‌ی `kv-gap` (۲۲ × ۲۸) داخل `Card` می‌نشیند. مقدار لاتین (ایمیل، نام کاربری، شبا) با `ltr`. مقدار تهی (`null`/`''`) خودکار «—» می‌شود.

ترتیب جفت‌ها = ترتیب فیلدهای فرم افزودن همان موجودیت.
