# WizardForm

الگوی ویزارد افزودن/ویرایش (کاربر): نوار مراحل، FormGrid چهارستونه و پاورقی دکمه‌ها.

الگوی `UserFormPage` + `userFormSchema.ts`:
- یک کامپوننت برای ساخت و ویرایش. `Card pad={false}`: نوار مراحل (دایره‌ی ۲۲px؛ فعال قرمز، انجام‌شده سبز با تیک؛ فقط مرحله‌های قبلی کلیک‌پذیر)، بدنه `22px 24px`، پاورقی `surface-2`.
- react-hook-form + zod، `mode: 'onTouched'`؛ **پیش از مرحله‌ی بعد `trigger(STEP_FIELDS[step])`**؛ خطا جلوی رفتن را می‌گیرد.
- مراحل کاربر: اطلاعات هویتی، آدرس و تماس (حداقل ۲ نفر از بستگان با موبایل)، اطلاعات بانکی، اطلاعات شغلی، مدارک، امنیت و نقش (موبایل ورود از کشویی موبایل‌های شخصی).
- پاورقی (راست به چپ): «ثبت کاربر» (فقط مرحله‌ی آخر؛ در ویرایش «ذخیره‌ی تغییرات» همیشه)، «مرحله بعد: نام ⟵»، «⟶ مرحله قبل»، «انصراف» (ghost، `useBack`)، و «مرحله ۲ از ۶».
- ذخیره ⇐ toast و `navigate(detail, {replace:true})`؛ خطای بک‌اند با `applyServerErrors` روی فیلدها ⇐ پرش به اولین مرحله‌ی خطادار + `Alert`.

نمونه‌ی واقعی: `assets/Screens/04-user-wizard.webp` و حالت خطا `05-user-wizard-errors.webp`.
