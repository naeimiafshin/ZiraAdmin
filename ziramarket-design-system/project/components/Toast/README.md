# Toast

پیام کوتاه نتیجه‌ی عمل، پایین وسط صفحه، ۴.۲ ثانیه.

`const toast = useToast(); toast('نقش کاربر ثبت شد.')` و خطا `toast(userMessage(e), 'error')`. متن موفقیت فعل گذشته با نتیجه‌ی دقیق: «نقش «کارشناس» به ۳ کاربر داده شد.»، «۴ مجوز به نقش افزوده شد.». خطای فیلدی فرم در toast نمی‌آید؛ کنار فیلد می‌نشیند. `ToastProvider` یک بار دور کل چیدمان است.
