# TableFilters

نوار جست‌وجو و فیلترهای بالای هر جدول، تمام‌عرض، با «حذف فیلترها» و شمارنده.

- جست‌وجو دو سهم (`flex:2`، زمینه `surface-3`)، هر فیلتر یک سهم، دکمه‌ی آیکونی «حذف فیلترها» (`IconFilterOff`، همیشه دیده می‌شود، بی‌فیلتر خاموش)، شمارنده در انتها («۷ کاربر»). کل عرض جدول را می‌پوشاند (قانون 2026-10-21).
- فیلتر کشویی «برچسب: مقدار»؛ خالی = «همه». فیلتر فعال زمینه‌ی بلاش و مقدار قرمز.
- `soon` روی فیلتر یا گزینه ⇐ غیرفعال با «به‌زودی». `range` ⇐ «از / تا». `stacked` ⇐ جست‌وجو یک ردیف تمام‌عرض و فیلترها در شبکه‌ی ۴ستونه (جدول‌های پرفیلتر). `extra` کنار جست‌وجو (`ColumnPicker`، فیلتر تاریخ) با `onReset`/`extraActive`.
- placeholder فهرست واقعی فیلدهای جست‌وجو: «جست‌وجو: نام، نام کاربری، موبایل یا کد پرسنلی».

## فیلترهای تأییدشده‌ی مدیریت کاربران
| جدول | جست‌وجو | فیلترها |
|---|---|---|
| کاربران | نام، نام کاربری، موبایل، کد پرسنلی | نقش (+ «بدون نقش»)، وضعیت، نشست فعال |
| نقش‌ها | کد، نام، دپارتمان، توضیحات | وضعیت، نقش، دپارتمان (+ «بدون دپارتمان») |
| تخصیص شعب — پرسنل | مثل کاربران | مثل کاربران |
| دپارتمان‌ها | کد، نام | (منتظر افشین) |
| اعلان‌های ارسال‌شده | عنوان، متن | موضوع، اولویت، گیرندگان |
| نشست‌ها | نام کاربر، IP، مرورگر، مکان | نقش، وضعیت (پیش‌فرض «فعال»)، نوع دستگاه |
| گزارش دسترسی‌ها | کد مجوز | کاربر، نتیجه، دلیل |
| تخصیص گروهی نقش | مثل کاربران | مثل کاربران؛ نقش پیش‌فرض «بدون نقش» |
