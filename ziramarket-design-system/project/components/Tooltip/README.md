# Tooltip

راهنمای شناور سراسری (TooltipLayer) برای هر دکمه، پیوند، گزینه و هر عنصر با data-tip.

یک بار در `App` نصب است. متن = `data-tip` ⇐ `aria-label` ⇐ متن دکمه؛ `data-tip=""` یعنی بدون راهنما؛ `data-tip-pos` برای جهت. تأخیر ۳۲۰ms؛ متن بلندتر از ۴۸ نویسه و ردیف جدول راهنما نمی‌گیرند. `title` بومی استفاده نشود. دکمه‌ی فقط‌آیکونی حتماً `aria-label`. (موس را روی دکمه‌ها نگه دارید.)
