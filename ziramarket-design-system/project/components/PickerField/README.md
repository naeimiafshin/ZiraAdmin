# PickerField

فیلد انتخاب از فهرست بلند: هم‌شکل Input با آیکون، مقدار، ✕ و فلش؛ کلیک ⇐ مودال جدول انتخابی.

به‌جای دکمه‌ی «انتخاب» جدا کنار فیلدها (قانون فرم درون‌خطی 2026-10-21). برای کارمند، مدیر مستقیم، مشتری، بازاریاب. `onOpen` مودال جدول انتخابی (جست‌وجو + فیلتر + صفحه‌بندی) را باز می‌کند؛ `onClear` مقدار را پاک می‌کند.
