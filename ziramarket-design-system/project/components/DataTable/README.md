# DataTable

تنها جدول پنل: یک table واقعی با ردیف‌های کارتی 46px، همه‌چیز وسط‌چین، بدون قید عرض.

## قانون‌های جدول (افشین 2026-10-20 و 2026-10-21؛ همه‌ی جدول‌های موجود و آینده)
1. فقط `DataTable` (یک `<table>`): سربرگ دقیقاً روی ستون داده.
2. بدون قید عرض ستون؛ **متن هرگز نمی‌شکند**؛ جدول پهن‌تر از صفحه اسکرول افقی می‌خورد.
3. **همه‌ی ستون‌ها وسط‌چین** (سربرگ و داده).
4. ستون کد با `code: true`: `ink-400`، 12px، وزن 500. رنگ/اندازه‌ی جدا برای کد ننویسید.
5. بدون آواتار. اعداد فارسی؛ ستون عددی `tnum`.
6. ارتفاع ثابت: سطر `row-height` 46px، سربرگ `head-height` 38px؛ دکمه داخل سلول 30px یا `size="sm"`.
7. هر جدول جست‌وجو و فیلتر دارد (`TableFilters`)؛ **فیلدهای فیلتر را افشین تعیین می‌کند** — پیش از ساخت بپرسید.
8. ستون اول معمولاً «ردیف» کم‌رنگ: `faNum((page-1)*pageSize+i+1)`.

## props
`columns: Column<T>[]` (`key`، `header`، `render(row,i)`، `code?`)، `rows` (`undefined` ⇐ اسکلت؛ `[]` ⇐ `empty`)، `rowKey`، `onRowClick` (ردیف `role=link`، Enter؛ hover `blush-50`)، `isSelected` (زمینه‌ی `brand-tint` + خط ۳px قرمز؛ جدول انتخابی)، `loading`، `error` + `onRetry`، `empty`، `expanded(row)` (پنل بازشونده زیر ردیف)، `variant` (`cards` پیش‌فرض؛ `flat` فقط اعلان‌های ارسال‌شده عیناً مطابق html).

## انتخاب چندتایی
ستون اول مربع انتخاب (`selectColumn` در ماژول کاتالوگ): سرستون = همه‌ی ردیف‌های قابل انتخاب همین صفحه؛ ردیف غیرقابل انتخاب خاموش با ستون «قابل تخصیص» که دلیل را می‌گوید. انتخاب بین صفحه‌ها می‌ماند.

> داده‌ی این پیش‌نمایش **نمونه** است؛ در پنل هر ردیف از API واقعی می‌آید.
