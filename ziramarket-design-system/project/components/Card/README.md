# Card

کارت سفید پایه‌ی همه‌ی بخش‌ها: گردی 22px، حاشیه frame-line، سایه shadow-card، padding 22px.

هر بخش صفحه یک `Card` است و عنوانش `SectionTitle`. `pad={false}` فقط برای کارتی که خودش سربرگ و پاورقی دارد (ویزارد). کارت‌های هم‌سطر همیشه هم‌ارتفاع و پویا هستند (`align-items: stretch`؛ قانون امنیت). کارت تو در تو نسازید؛ داخل کارت برای جدا کردن، خط `line-soft` یا کادر `surface-2` به کار برید.
