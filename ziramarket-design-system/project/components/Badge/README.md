# Badge

نشان قرصی وضعیت با نقطه‌ی رنگی: فعال، غیرفعال، در انتظار، قفل، لغوشده.

برای **وضعیت** یک موجودیت (کاربر، نشست، نقش، اعلان). برای برچسب‌های غیر وضعیتی (نقش، دپارتمان) از `Chip` استفاده کنید.

| tone | رنگ | معنا در مدیریت کاربران |
|---|---|---|
| `success` | `success` روی `success-tint` | فعال، موفق، «بله» (قابل تخصیص) |
| `neutral` | `ink-500` روی `surface-3` | غیرفعال، منقضی، پیش‌نویس، کارمند |
| `info` | `info` روی `info-tint` | در انتظار، سوپرادمین، Branch Master |
| `warning` | `warning` روی `warning-tint` | قفل، رد شده |
| `danger` / `brand` | `brand` روی `brand-tint` | لغوشده، فوری |

ارتفاع `badge-height` (26px)، متن `badge` (12px/700). برچسب و tone هر enum بک‌اند در `labels.ts` همان ماژول تعریف می‌شود (`USER_STATUS`، `USER_TYPE`، `SESSION_STATUS`) و مقدار ناشناخته با `neutral` و متن خام نمایش داده می‌شود.

**کنتراست:** `warning` روی `warning-tint` حدود ۳.۳:۱ است (زیر ۴.۵ برای متن ۱۲px). منبع دست نخورده؛ نقطه و برچسب متنی معنا را می‌رسانند.
