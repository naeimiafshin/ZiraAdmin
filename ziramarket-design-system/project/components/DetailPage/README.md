# DetailPage

الگوی صفحه‌ی جزئیات (کاربر): کارت hero، تب‌های همان فرم افزودن، کارت‌های KeyValue و ستون کناری.

الگوی `UserDetailPage`:
1. `PageHead back={useBack('/identity/users')}` + «ویرایش» با مجوز.
2. کارت hero (هاله‌ی `blush-100` در گوشه): `Avatar` 64 (فقط شخص)، نام `page-title` + Badgeهای وضعیت و نوع؛ زیر آن متای 12.5px (کد پرسنلی، نقش، عنوان شغلی، آخرین ورود).
3. `UnderlineTabs` با همان ۶ تب فرم افزودن.
4. بدنه دوستونه: کارت‌های بخش (`SectionTitle` + `KeyValue` دوستونه) + ستون کناری ۳۶۰px «آخرین فعالیت‌ها» (نقطه‌ی رنگی نتیجه).
5. عمل‌های داخل تب (تغییر نقش، وضعیت، بازنشانی رمز، حذف مدرک) هر کدام `Card` جدا + `InfoBanner` قاعده + مودال تأیید + toast نتیجه.

پروفایل من (`/account/profile`) همین الگوست، فقط‌خواندنی. نمونه‌ی واقعی: `assets/Screens/03-user-detail.webp`.
