# SoonTag

برچسب «به‌زودی» برای قابلیتی که بک‌اند هنوز ندارد، با راهنمای دلیل.

قانون: هیچ داده‌ی ساختگی. چیزی که بک‌اند ندارد غیرفعال با «به‌زودی» نمایش داده و در `docs/<DOMAIN>_BACKEND_GAPS.md` ثبت می‌شود. `tip` دلیل را می‌گوید («ویرایش پروفایل توسط خود کاربر هنوز در بک‌اند نیست»). کنار دکمه‌ی غیرفعال، در `SectionTitle extra`، یا در گزینه/فیلتر (`soon: true`).
