# Avatar

دایره‌ی حرف اول با رنگ ثابت از شناسه؛ فقط در hero صفحه‌ی جزئیات و منوی کاربر.

رنگ از `avatarColor(seed)` (یکی از ده رنگ `avatar-01`…`avatar-10` بر اساس شناسه، همیشه همان رنگ برای همان کاربر) و حرف اول نام. اندازه‌ها: 34 (منوی کاربر)، 40 (سربرگ منو)، 64 (hero).

**قانون:** در جدول‌ها و فهرست‌هایی که شخص یکی از ستون‌هاست، آواتار نمایش داده نمی‌شود (افشین 2026-10-20). فهرست گفت‌وگوها هم بی‌آواتار است.
