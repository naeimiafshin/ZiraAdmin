# InfoBanner

بنر توضیحی آبی یا نارنجی برای قاعده‌ی کسب‌وکار یا محدودیت بخش.

برای توضیح یک قاعده پیش از عمل («هر کارمند فقط یک نقش فعال دارد»، «فقط سوپرادمین ماتریس را تغییر می‌دهد»). `tone="warning"` برای محدودیت یا خطر («این نقش غیرفعال است»). متن کوتاه، یک یا دو جمله. برای خطای درخواست از `ErrorBox` یا `Alert` استفاده کنید.
