# Input

ورودی متنی برچسب‌دار 42px با خطا، راهنما، حالت لاتین و قالب هنگام تایپ.

- **ارقام:** هر رقم تایپ‌شده خودکار فارسی نمایش داده می‌شود؛ مقدار ارسالی با `clean`/`toLatinDigits` لاتین می‌شود. استثنا `latin` (کد، نام کاربری، ایمیل، IP) و `type="password"`.
- **قالب:** `format` هنگام تایپ (موبایل `formatMobileInput`، کارت `formatCard`، شبا `formatIban`، مبلغ `groupMoney`).
- **موبایل:** فقط رقم، ۱۱ رقم، شروع با ۰۹؛ پیام دقیق `mobileProblem` («شماره موبایل باید ۱۱ رقم باشد (الان ۷ رقم است)») پیش از مرحله‌ی بعد و ذخیره.
- **حالت‌ها:** فوکوس حاشیه‌ی `brand` + `focus-ring`؛ نامعتبر زمینه‌ی `brand-tint-2` و خطا `hint` قرمز زیر فیلد؛ غیرفعال/فقط‌خواندنی زمینه‌ی `surface-3` و متن `ink-400` با `hint` دلیل («از این فرم قابل تغییر نیست.»).
- با `register()` react-hook-form کار می‌کند (`forwardRef`).
