# PageHead

سطر بالای محتوای صفحه: «بازگشت» + عنوان و زیرعنوان در راست، عمل‌ها در چپ.

عنوان اصلی صفحه در **سربرگ** پنل است (از منو)؛ پس صفحه‌های فهرست فقط `actions` می‌دهند. صفحه‌های فرعی (جزئیات، ویزارد، پروفایل) `back` و در صورت نیاز `title` دارند.

- `back` همیشه `useBack('/fallback')`: به صفحه‌ای برمی‌گردد که کاربر از آن آمده؛ ورود مستقیم ⇐ صفحه‌ی والد. مسیر ثابت ممنوع.
- `actions`: دکمه‌ی اصلی صفحه (فقط با مجوز؛ بدون مجوز پنهان).
- ارتفاع حداقل 44px؛ دکمه‌ی بازگشت `control-height`.
