# ErrorBox

کادر خطای بارگذاری با پیام فارسی (userMessage) و «تلاش دوباره».

برای خطای query (فهرست، جزئیات). پیام با `userMessage(error)`: متن فارسی بک‌اند همان‌طور؛ انگلیسی ⇐ پیام عمومی وضعیت (۴۰۳ «به این بخش دسترسی ندارید.»، ۴۰۴ «مورد درخواستی پیدا نشد.»، ۵xx با «کد پیگیری»). `onRetry` ⇐ `refetch`. ۴۰۳ بک‌اند صادقانه همین‌جا نمایش داده می‌شود.
