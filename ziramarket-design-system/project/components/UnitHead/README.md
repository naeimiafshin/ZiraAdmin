# UnitHead

واحد پول و متراژ: «ریال» کنار مبلغ (Rial)، در جدول فقط در سرستون (UnitHead)، و مبلغ تخفیف‌خورده (DiscountedPrice).

قانون‌های سراسری مبلغ (افشین 2026-10-23 تا 2026-10-25):
- هر مبلغ ریالی هنگام **تایپ و نمایش** جداکننده‌ی هزارگان «٬» با ارقام فارسی دارد: «۱٬۲۵۰٬۰۰۰». ورودی: `value={groupMoney(state)}` و ذخیره با `moneyDigits`؛ نمایش با `faNum`. درصد، تعداد، کد و مهلت جداکننده ندارند.
- بیرون از جدول «ریال» با `Rial` کنار عدد؛ **در جدول فقط در سرستون** با `UnitHead` («قیمت» + «(ریال)» کوچک در سطر دوم) و سلول عدد خالی.
- متراژ همیشه `m²` انگلیسی: `UnitHead unit="m²"`.
- مبلغ تخفیف‌خورده فقط با `DiscountedPrice`: «پایه:» خط‌خورده‌ی قرمز نازک، «تخفیف:» سبز، «قیمت نهایی:» سبز پررنگ.

در ماژول مدیریت کاربران فقط «درصد قرارداد فروش» عددی است (بدون جداکننده).
