# SecurityActions

الگوی کارت عمل‌های حساب: ردیف عنوان و توضیح در راست، دکمه در چپ، جداکننده بین ردیف‌ها.

از پروفایل من (تب «امنیت و نقش»): تغییر رمز عبور (مودال)، تنظیمات اعلان‌ها (مودال جدول موضوع‌ها)، خروج از همه‌ی دستگاه‌ها (danger + تأیید). هر ردیف: عنوان `label` پررنگ + توضیح پیامد عمل در یک جمله. همین الگو برای ردیف‌های صفحه‌های تنظیمی (سیاست‌های امنیتی) با کنترل به‌جای دکمه.
