# Modal

پنجره‌ی مودال: portal، Esc و کلیک بیرون می‌بندد، سربرگ با ✕، پاورقی خاکستری با دکمه‌ها.

- **تأیید عمل خطرناک** (`width` 440–520): متن کوتاه که پیامد را می‌گوید + پاورقی `[danger: «حذف»] [ghost: «انصراف»]`. برای برداشتن گروهی، شمار دقیق در دکمه («برداشتن ۳۸ مجوز»).
- **فرم کوتاه** (520–640): `FormGrid cols={2}`.
- **جدول انتخابی** (960–1040): `TableFilters` + `DataTable isSelected` + `Pagination`؛ پاورقی با شمار انتخاب و دکمه‌ی تأیید («تخصیص نقش به ۳ کاربر»).
- خطا داخل مودال با `Alert` بالای بدنه؛ مودال با خطا بسته نمی‌شود.
- پرده `overlay` + blur 3px، گردی `radius-xl`، سایه `shadow-lg`، انیمیشن pop.
