# Chip

برچسب قرصی گرم (بلاش) برای نقش، دپارتمان و شمارنده؛ با tip متن کامل در راهنمای شناور.

برای مقدارهای برچسبی که وضعیت نیستند: نقش کاربر در جدول، دپارتمان‌ها در پروفایل، نام گروه‌ها. زمینه `blush-50`، حاشیه `blush-line`، متن `logo-wine` (۶.۶:۱ روی سفید). متن بلند با سه‌نقطه کوتاه می‌شود؛ `tip` متن کامل را در راهنمای شناور نشان می‌دهد.

نباید: برای وضعیت (Badge) یا برای دکمه.
