# SectionTitle

عنوان بخش داخل کارت با میله‌ی قرمز گرادیان؛ سمت مقابل جای شمارنده یا دکمه (extra).

`h3` با `section-title` (15px/700) و میله‌ی ۵×۱۸ گرادیان برند در ابتدای سطر (راست). `extra` در انتهای سطر (چپ): شمارنده («۲۱ از ۳۸۴ مجوز»)، دکمه‌ی `sm` یا `SoonTag`. فاصله تا محتوا `space-grid` (18px).
