# Dropdown

فهرست کشویی استاندارد پنل: دکمه‌ی هم‌شکل ورودی و فهرست در portal با گزینه‌ی انتخاب‌شده‌ی قرمز و تیک.

پایه‌ی `Select`، فیلترهای `TableFilters` و ماه/سال تقویم. فهرست با `position: fixed` در portal باز می‌شود (داخل مودال و جدول بریده نمی‌شود؛ اگر پایین جا نباشد بالا). بستن: کلیک بیرون، Esc، Tab؛ پیمایش با کلیدهای جهت. فهرست باز: گردی `radius-cell`، padding 6px، سایه `shadow-dropdown`، حداکثر ارتفاع 320px.
