# لوگوها

- `logo-lockup.svg` (لوگوی دوم، `Second_Logo.svg`؛ ۱۹۲×۴۰): نشان + نام «زیرا مارکت». هر جا نام کنار نشان است: پنل برند صفحه‌ی ورود (ارتفاع 64px)، مگامنو. کامپوننت `BrandLockup`.
- `logo.svg` (لوگوی اول، `Main_logo.svg`؛ نسبت ۳۱×۲۷): فقط نشان. ریل منو، فاوآیکون، واترمارک کم‌رنگ صفحه‌ی ورود (۹٪ شفافیت). کامپوننت `BrandMark`.
- هر دو گرادیان صورتی تا زرشکی خودشان را دارند (همان `--logo-gradient`: از `#DA9999` تا `logo-ink`) و رنگشان از متن کنار ارث نمی‌برند. **فقط روی زمینه‌ی روشن** (`surface`، `canvas`، `blush-*`)؛ هرگز روی `brand`، گرادیان قرمز یا زمینه‌ی تیره.
- نام برند را با متن کنار نشان نسازید؛ نشان را بازنقاشی، کشیده یا رنگ‌عوض نکنید.
