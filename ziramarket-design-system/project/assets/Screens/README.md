# اسکرین‌شات‌های ماژول مدیریت کاربران

صفحه‌های واقعی پنل در ۱۴۴۰×۹۰۰ روی بک‌اند واقعی با داده‌ی آزمایشی (ZiraAdmin@75486b4). مرجع دیداری برای ساختن ماژول تازه: چیدمان، فاصله‌ها، جدول، فیلترها و حالت‌ها را از این‌ها مقایسه کنید. نام‌ها و شماره‌ها داده‌ی تست‌اند، نه داده‌ی واقعی.

| فایل | صفحه |
|---|---|
| `01-login.webp` | ورود |
| `02-users-list.webp` | فهرست کاربران (قاب کامل: سایدبار باز، سربرگ، نوار فیلتر، جدول) |
| `03-user-detail.webp` | جزئیات کاربر (hero، تب‌ها، KeyValue، آخرین فعالیت‌ها) |
| `04-user-wizard.webp` | ویزارد افزودن کاربر، مرحله‌ی اول |
| `05-user-wizard-errors.webp` | ویزارد با خطاهای اعتبارسنجی پیش از مرحله‌ی بعد |
| `06-roles-list.webp` | فهرست نقش‌ها |
| `07-role-matrix.webp` | ماتریس مجوز نقش با «انتخاب همه» |
| `08-bulk-assign-modal.webp` | مودال تخصیص گروهی نقش (جدول انتخابی) |
| `09-departments.webp` | دپارتمان‌ها |
| `10-branch-access.webp` | تخصیص شعب |
| `11-notifications.webp` | اعلان‌ها (ارسال + ارسال‌شده‌ها با variant flat) |
| `12-sessions.webp` | نشست‌ها |
| `13-access-log.webp` | گزارش دسترسی‌ها (کارت‌های آمار + دلایل + جدول) |
| `14-chat.webp` | گفت‌وگوهای خصوصی |
| `15-profile.webp` | پروفایل من |
| `16-security-policy.webp` | سیاست‌های امنیتی (الگوی صفحه‌ی تنظیمی) |
| `17-megamenu.webp` | مگامنو (جنگل بلور، قرص‌های شیشه‌ای، موزاییک) |
